# Cadrage technique - Feux de forêt dans le Loiret

## Projet et dépôt

Le projet étudie les feux de forêt en Centre-Val de Loire, avec un focus sur le Loiret (45).

[Dépôt GitHub du projet](https://github.com/abdelbasirmn/feux-de-foret-centre-val-de-loire)

## Sources prévisionnelles

- BDIFF et Copernicus CEMS
- IGN BD ALTI, IGN BD TOPO, Météo France, Météo France IFM
- Carroyage DFCI et OCS GE
- ADMIN EXPRESS et BD Forêt V2

## Stack proposée

| Usage | Choix proposé |
|---|---|
| Exploration | Python, VS Code et Jupyter Notebook |
| Pipeline de données | Databricks Free Edition, Python, PySpark et SQL |
| Stockage | Delta Lake |
| Architecture des données | Bronze / Silver / Gold |
| Modélisation décisionnelle | Modèle en étoile |
| Datavisualisation | Power BI Desktop |
| Versionnement et documentation | GitHub |
