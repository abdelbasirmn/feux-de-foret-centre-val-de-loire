# Fiche d'identité de la source — BDIFF

**Base de Données sur les Incendies de Forêts en France**

| Rubrique | Valeur |
| --- | --- |
| Propriétaire et système | Ministère de l'Agriculture, à travers l'application nationale BDIFF. Le producteur indiqué sur data.gouv.fr est l'IGN. Les données sont collectées auprès des SIS, DDT(M), ONF et d'autres acteurs. |
| Mode d'accès et format | On peut consulter et filtrer les données directement sur le portail BDIFF, puis télécharger un fichier ZIP contenant les données au format CSV et des documents explicatifs en PDF. |
| Grain (une ligne = ?) | Une ligne correspond à un incendie recensé, avec notamment la commune où le feu s'est déclaré. |
| Emprise géographique | Toute la France, y compris la Corse et les départements d'outre-mer. Pour notre projet, on s'intéresse au Centre-Val de Loire et plus particulièrement au Loiret. |
| Période réellement couverte par les données | De 2006 à 2025 au niveau national, avec des données remontant à 1973 pour certains départements méditerranéens. Le fichier que j'ai consulté concerne le Centre-Val de Loire pour l'année 2025. |
| Date de dernière mise à jour affichée sur la fiche | 13/12/2025 sur data.gouv.fr. |
| Fréquence de mise à jour | Une fois par an, après validation des données collectées. |
| Volumétrie | Non vérifiée, car je n'ai pas compté le nombre total de lignes du fichier téléchargé. |
| Clés disponibles | L'identifiant de l'incendie, le code INSEE de la commune, le département et la date d'alerte. On pourrait notamment utiliser le code INSEE et la date pour croiser ces données avec d'autres sources. |
| Données personnelles | Je n'ai pas identifié de données nominatives dans les informations publiques consultées. |
| Licence | Licence Ouverte / Open Licence version 2.0. |
| Questions de mon analyse auxquelles elle pourrait répondre | Cette source pourrait m'aider à savoir dans quelles zones du Loiret il y a eu le plus de départs de feu, mais aussi à identifier les périodes de l'année où ils sont les plus fréquents. Elle permettrait également de voir les zones où les incendies ont causé le plus de dégâts en termes de surfaces brûlées et d'analyser les principales causes lorsqu'elles sont renseignées. En la croisant avec les données météorologiques, on pourrait aussi étudier si les départs de feu sont plus fréquents lorsque le niveau de danger est élevé. |

## Limites identifiées

- Tous les incendies ne sont pas forcément recensés de la même manière selon les départements et les années.
- Il faudra faire attention aux données antérieures à 2020 pour les départements situés en dehors de la zone méditerranéenne.
- Les causes des départs de feu ne sont pas toujours renseignées.
- Les données de l'année en cours ne sont pas encore disponibles.
- Cette source ne permet pas à elle seule de savoir si les moyens humains et matériels disponibles sont suffisants dans les différentes zones du Loiret.

## Conclusion

Je pense que BDIFF est l'une des sources principales à retenir pour notre projet, car elle nous permet d'avoir un historique des incendies, de savoir où et quand ils ont eu lieu, mais aussi de connaître les surfaces brûlées et certaines causes des départs de feu.

En la croisant avec d'autres sources, notamment les données météorologiques et celles concernant les moyens disponibles, on pourrait mieux identifier les zones et les périodes où il faudrait renforcer le dispositif.
